This box has two kinds of controls: table buttons and right-click (context menu) buttons.

Table buttons:
- Place: Puts cards/tokens in their play positions.
- KT table: Places items using the Kill Team table layout.
- Recall: Pulls tracked items back into the box.

Right-click (context menu) buttons:
- Update: Refreshes card stats/rules from this box onto matching cards already on the table.
- Reset: Resets this box and respawns its tracked contents.
- Clear Layout: Clears any saved custom layout and returns Place behavior to defaults.

Note: Save Layout/Setup mode is currently disabled in this release, so Place uses default positions.
